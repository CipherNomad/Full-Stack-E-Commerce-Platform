# Trendify – Full-Stack Fashion E-Commerce Platform (MERN)

Live Demo: https://full-stack-e-commerce-platform.netlify.app/

Developed a fully functional fashion e-commerce web application using the **MERN stack (MongoDB, Express.js, React.js, Node.js)**, inspired by **Myntra’s UI/UX** and features. Trendify allows users to browse, filter, and purchase products with an intuitive interface, secure authentication, real-time cart updates, and a modern responsive design.

---

## 🌟 Features

* ✅ **Dynamic Product Catalog** – Browse products with categories, filtering, and search.
* ✅ **User Authentication** – Secure login/signup using **JWT & bcrypt**.
* ✅ **Real-Time Cart System** – Add, remove, and update quantities instantly.
* ✅ **RESTful API Integration** – Smooth communication between frontend and backend.
* ✅ **MongoDB Atlas Integration** – Cloud-based, scalable database.
* ✅ **Responsive UI/UX** – Built with **React.js + Tailwind CSS**.
* ✅ **Cloud Deployment** – Hosted on **AWS / Render / Vercel** for high availability.

---

## 🚀 Project Goal

To replicate a **real-world e-commerce experience** while showcasing strong skills in:

* Full-stack web development
* API architecture
* Database design
* Cloud deployment & scalability

---

## 🛠️ Tech Stack

* Frontend: React.js, Tailwind CSS
* Backend: Node.js, Express.js
* Database: MongoDB & MongoDB Atlas
* Auth: JWT, bcrypt
* Deployment: AWS / Render / Vercel

---

## 📌 Installation & Setup

```
# Clone the repository
git clone <repo-link>
cd project-folder

# Install dependencies
npm install
cd client && npm install

# Start backend
npm run dev

# Start frontend
cd client
npm start
```
